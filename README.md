# 📅 Responsive Calendar

A clean and responsive **Calendar UI** built using **HTML and CSS**, with a focus on modern CSS layout techniques.

This project was created as part of my frontend development learning journey, where I practiced **CSS Flexbox, CSS Grid, spacing, alignment, and responsive layout design**.

## 🚀 Features

* 📅 Clean calendar interface
* 🎨 Modern and simple UI
* 📐 Built with CSS Grid
* 🔄 Flexbox used for layout and alignment
* 📱 Responsive design
* 🧩 Organized HTML & CSS structure
* 💻 Beginner-friendly frontend project

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **CSS Flexbox**
* **CSS Grid**

## 🎯 What I Practiced

Through this project, I practiced:

* CSS Grid for creating the calendar structure
* Flexbox for alignment and positioning
* Responsive layout techniques
* Width, height, margin, and padding
* Typography and spacing
* CSS positioning
* Clean and structured HTML/CSS
